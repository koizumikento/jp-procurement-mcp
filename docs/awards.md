# 落札実績

## ツール

### `search_awards`

`search_awards` で年度別全件または日次差分を、案件名・府省・法人番号で絞り込みできます。

```json
{
  "fiscal_year": 2025,
  "query": "地図",
  "limit": 3
}
```

年度別の全件データを検索するには `fiscal_year` を指定します。使うのは調達ポータルが月ごとに公表するファイルです。特定の日に追加された落札実績を探すには、日次差分ファイルの作成日を `published_on` に指定します。落札決定日での検索には使えません。日次差分の提供期間は過去約2か月です。

複数の事業者が落札した案件では、事業者ごとに結果を返します。落札価格は精度を保つため、元データの文字列で返します。

検索は取得したZIPに対して手元で実行します。ZIPはディスクに保存せず、同じ実行プロセス内で最大2件を保持します。同じ30分枠の照会では取得済みのZIPを再利用します。

### `summarize_awards`

年度別ファイルを1〜3年度指定して、年度・府省コードごとに案件数と価格を集計します。案件名の部分一致（`query`）や府省コード（例 `"L1"` は法務省）で絞り込めます。各年度に使用したファイル名とダウンロードURLを返します。

| 結果 | 数え方 |
| --- | --- |
| `matching_row_count` | 条件に一致する落札実績の行数 |
| `distinct_case_count` | 一致する行が1つ以上ある調達案件番号の数 |
| `ambiguous_case_count` | 同じ年度・府省・案件番号で、元ファイルに複数行ある案件数 |
| `priced_case_count` / `unpriced_case_count` | 元ファイルに1行だけある案件を、有効な落札価格の有無で区分した件数 |
| `single_row_award_price_total` | 価格が有効な単一行の案件だけの合計。小数精度を保つ文字列で、該当がなければ `null` |

同じ案件に複数の落札行がある場合は、重複計上を避けるため価格集計から除外します。府省全体の落札価格を比較する場合は、価格集計から除外された案件数も確認してください。
