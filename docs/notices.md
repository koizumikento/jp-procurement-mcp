# 調達公告

## MCPツール

### `search_notices`

次の検索条件のうち、キーワード・件名・発注機関・都道府県のいずれか1つ以上を指定します。`limit` は返す件数で、1〜50件です（既定10件）。

| 引数 | 条件 |
| --- | --- |
| `query` / `project_name` / `organization_name` | キーワード / 件名 / 発注機関名 |
| `prefecture_code` | 2桁の都道府県コード。東京都は `"13"` |
| `category` | `1` 物品、`2` 工事、`3` 役務 |
| `procedure_type` | `1` 一般競争入札、`2` 簡易公募型競争入札、`3` 簡易公募型指名競争入札 |
| `qualification` | 入札資格の等級。例 `["A", "B"]` |
| `issue_period` / `tender_start_period` / `opening_period` / `delivery_deadline_period` | 公告日（不明なら取得日） / 入札開始日 / 開札日 / 納入期限日の期間 |

期間には単日 `2026-04-01`、両端を含む期間 `2026-04-01/2026-04-30`、開始日以降 `2026-04-01/`、終了日以前 `/2026-04-30` を指定できます。条件はポータル側で適用します。データが未整備の項目もあるため、日付や資格などの条件を追加すると、該当項目が空欄の公告が検索から外れる場合があります。

`include_details=true` にすると、公告1件につき本文の先頭2,000文字と添付リンクの先頭10件までを返します。本文が上限を超えると `body_truncated`、添付リンクが上限を超えると `attachments_truncated` が `true` になります。公告の原文や添付ファイルはリンク先で確認してください。

`published_at` はポータルの公告日で、公告日が分からない場合は取得日です。`collected_at` はポータルが取得した日時です。`tender_start_at` は入札開始日です。申請の締切や参加条件は公告原文で確認してください。
